על הקורס

מה זה JavaScript?

JavaScript היא שפת תכנות דינמית ומפורשת ו– חלשה טיפוסית, שנבנתה כדי לרוץ בתוך סביבות מארחות (למשל דפדפן אינטרנט).

היא חלק כמעט מכל אתר מודרני, משום שהיא הדבר היחיד שמאפשר למתכנת לשנות את התוכן של הדף בזמן אמת. כל דבר שנפתח, נסגר, זז או משתנה לרוב מערב JavaScript.

יש גם אתרים שלמים שנבנים כמעט לגמרי באמצעות JavaScript, לדוגמה בעזרת ספריות כמו React על זה נדבר בהמשך הקורס. 🙂

מה נלמד בקורס?

הקורס מלמד JavaScript מהבסיס לא צריך ידע מוקדם בכלל.

נצלול לעקרונות החשובים, תכונות מתקדמות, תבניות עבודה ומושגים ברמה של מפתח מקצועי.

דרישות מקדימות

  • ידע בסיסי ב-HTML וב-CSS חובה
  • אין צורך להיות מתכנת מתקדם
  • לא צריך שום ידע קודם ב-JavaScript
