# 🎮 Blackjack Game Project

The game start with you and the dealer having two open cards on your deck.
To win the game you must have a higher score then the dealer or achive 21 score in total, if your score is above 21 you lose
or if the dealer manage to achive higher score then you then you lose.
You press the button "HIT" to add another card to your deck or you can chose to "Stand" and end your turn.
you press "new-game" to start a new round.

## 📌The project Description

This project is a fully interactive Blackjack game built using HTML, CSS, and JavaScript.
The player competes against the computer dealer using a real card deck fetched from an external API.

The project was developed using modern JavaScript concepts that includes:

- API integration
- Fetch API
- Async / Await
- Object-Oriented Programming (OOP)
- Classes
- DOM Manipulation
- Event Listeners
- Sound effects and background music
- Scoreboard system
- Interactive user interface
